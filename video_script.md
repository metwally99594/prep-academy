# 🎬 PrepAcademy Elite — Promo Video Concept

**Titel:** „Der letzte Schritt" (الخطوة الأخيرة)
**Dauer:** 60–90 Sekunden
**Stil:** Cinematic · Emotional · Dark/Gold · Typography-heavy
**Audio:** Orchestral build-up → Drop → Emotional piano outro
**Sprache:** Deutsch (mit englischen/arabischen Untertiteln)

---

## SCENE 1 — THE WEIGHT (0–10s)

```
VISUAL:
Nacht. Eine kleine Wohnung in Bremen/Wien.
Ein Tisch voller Bücher, Notizen, Kaffeetassen.
Eine Hand blättert müde durch ein dickes Lehrbuch.
Die Uhr tickt. 2:47 AM.

TEXT ON SCREEN (fade in, letter by letter):
„2.500 Seiten."
„12 Fachgebiete."
„Eine Prüfung."

SOUND: Subtle clock ticking, heavy breathing. Slow piano note.

MOOD: Erschöpfung. Der Druck ist spürbar.
```

## SCENE 2 — THE DOUBT (10–18s)

```
VISUAL:
Close-up: Gesicht eines Arztes (Ende 20, ernst, müde).
Er schließt die Augen. Reibt sich die Stirn.
Flash-cut: Leeres Multiple-Choice-Blatt. Ein Stift zittert.

TEXT (cut to black, then fade in):
„Kenntnisprüfung."
„Nostrifizierung."
„Stichprobentest."

SOUND: Music pauses. Silence. Then a deep heartbeat: BUM... BUM...

MOOD: Die Realität der Prüfungsangst.
```

## SCENE 3 — THE DISCOVERY (18–28s)

```
VISUAL:
Handy-Vibration. Eine Benachrichtigung:
„PrepAcademy Elite — 30 Tage kostenlos testen"

Der Arzt zögert. Tippt dann.
Close-up: Der Bildschirm leuchtet auf — goldene UI, Fragen, Statistiken.

TEXT (swipe animation):
„Quiz → KI-Analyse → Podcast → Notebook"

SOUND: Ein leichter Synth-Swell, hoffnungsvoll. Ein „Pling" beim UI-Element.

MOOD: Ein Licht am Ende des Tunnels.
```

## SCENE 4 — THE TOOLS (28–48s) — MONTAGE 🔥

```
Jede Szene = 2–3 Sekunden. Fast Cut. Energie steigt.

─── 4a ───
KI Medical Analyzer: Ein EKG wird hochgeladen.
Text: „Multi-AI Analyse (Gemma 4 · Nemotron · Qianfan)"
Die KI schreibt den Befund in Echtzeit.
SOUND: Sci-fi-ui-whir. BASS DROP.

─── 4b ───
Challenge Mode: Zwei Ärzte im Duell.
Balken wackeln. 50/50. Einer gewinnt.
Text: „Challenge Mode — Gegen Freunde antreten"
SOUND: Wettkampf-Gong.

─── 4c ───
Exam Simulation: Timer läuft runter. 59:59... 58:30...
Letzte Frage. User klickt „Abschließen".
Ergebnis: 84%. 🎉
Text: „Realistische Prüfungssimulation"
SOUND: Timer + Success chime.

─── 4d ───
Daily Podcast: Arzt joggt mit Kopfhörern.
„Episode 7: Notfallmedizin — Akutes Koronarsyndrom"
Text: „Tägliche Lern-Podcasts"
SOUND: Podcast-Stimme + Laufschritte.

─── 4e ───
KI Notebook: PDF wird hochgeladen.
KI analysiert. Extrahiert Prüfungsrelevantes.
Text: „PDF Notebook — Mit KI verstehen"
SOUND: Whoosh + Snap.

─── 4f ───
Statistiken: Streak-Kalender. 37 Tage 🔥.
Diagramme steigen. Badges fliegen rein.
Text: „Dein Fortschritt. Deine Erfolge."
SOUND: Aufbauend. Orchestral.
```

## SCENE 5 — THE BREAKTHROUGH (48–55s)

```
VISUAL:
Der Arzt schaut wieder auf den Bildschirm.
Diesmal: Ergebnis bestanden. 78%.
Er lehnt sich zurück. Lächelt zum ersten Mal.

ZOOM IN auf seine Augen — darin spiegelt sich:
Das goldene PrepAcademy-Logo.

TEXT:
„Vorbereitet. Selbstbewusst. Bereit."

SOUND: Music reaches peak. Ein goldener Akkord.
```

## SCENE 6 — THE FUTURE (55–65s)

```
VISUAL:
Tag. Heller Flur. Ein Krankenhaus.
Der Arzt — jetzt im weißen Kittel — geht einen Gang entlang.
Eine Pflegerin nickt ihm zu. Ein Patient lächelt.
Er tritt ins Licht.

TEXT (fade in, groß, golden):
„Deine Zukunft beginnt hier."

LOGO erscheint.
„PrepAcademy Elite"
„prepacademy-med.com"

SOUND: Emotionales Piano-Outro. Ausklang.

MOOD: Geschafft. Angekommen. Arzt in Österreich. 🇦🇹
```
