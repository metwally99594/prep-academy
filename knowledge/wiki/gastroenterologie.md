# Gastroenterologie

## Gastroösophageale Refluxkrankheit (GERD)

- **Pathophysiologie**: Insuffizienz des unteren Ösophagussphinkters, Hiatushernie
- **Symptome**: Sodbrennen, saures Aufstoßen, retrosternaler Schmerz, Dysphagie
- **Diagnostik**: Endoskopie (Ösophagitis, Los-Angeles-Klassifikation), 24h-pH-Metrie, Impedanzmessung
- **Therapie**: PPI (Protonenpumpeninhibitoren — Omeprazol, Pantoprazol), Lebensstilmodifikation, ggf. Fundoplicatio
- **Komplikationen**: Ösophagusulzera, Striktur, Barrett-Ösophagus (Präkanzerose → Adenokarzinom)

## Ulkuskrankheit

| | Magenulkus | Duodenalulkus |
|---|---|---|
| **Schmerz** | Postprandial (essen → Schmerz) | Nüchtern/Nachts (Schmerz → Essen bessert) |
| **Lokalisation** | Magenantrum/Kurvatur | Bulbus duodeni |
| **Pathogenese** | NSAR häufiger, H. pylori | H. pylori häufiger |

- **Diagnostik**: ÖGD (Goldstandard), H. pylori-Test (Urease-Schnelltest, ¹³C-Atemtest, Stuhl-Antigen)
- **Therapie**: PPI + H. pylori-Eradikation (z.B. Pantoprazol + Amoxicillin + Clarithromycin für 7 Tage), NSAR-Absetzen

## GI-Blutung

| | Obere GI-Blutung | Untere GI-Blutung |
|---|---|---|
| **Ursachen** | Ulkus, Varizen, Mallory-Weiss, Erosionen | Divertikel, Hämorrhoiden, Angiodysplasie, Karzinom, Polypen |
| **Klinik** | Hämatemesis, Meläna, Teerstuhl | Hämatochezie (frisches Blut), TEESTUHL |
| **Stabilisierung** | 2 großlumige Zugänge, Volumengabe, PPI-Bolus | Kreislaufstabilisierung, Endoskopie/Koloskopie |

- **Notfall bei Varizenblutung**: Endoskopische Ligatur + Terlipressin/Somatostatin + prophylaktische Antibiotika (Norfloxacin)

## Leberzirrhose

- **Ätiologie**: Alkohol, Virushepatitis (B, C), NAFLD/NASH, Autoimmunhepatitis, Hämochromatose, M. Wilson, α1-Antitrypsin-Mangel
- **Child-Pugh-Stadium**: A (5-6 Punkte, kompensiert) → B (7-9) → C (10-15, dekompensiert); Punkte für Bilirubin, Albumin, INR, Aszites, hepatische Enzephalopathie
- **Komplikationen**: Portale Hypertension / Aszites / Ösophagusvarizen / Hepatische Enzephalopathie / Hepatorenales Syndrom (HRS) / Spontan bakterielle Peritonitis (SBP) / Hepatozelluläres Karzinom (HCC)
- **Diagnostik**: Sonographie, FibroScan, Leberbiopsie, Labor (Bilirubin, Transaminasen, GGT, AP, Quick/INR, Albumin)
- **Therapie**: Ätiologie behandeln, Komplikationen managen (Aszites: Diuretika (Spironolacton + Furosemid), SBP: Antibiotika, Varizen: β-Blocker/Ligatur, HE: Laktulose/Rifaximin)

## Cholelithiasis & Cholezystitis

- **Risikofaktoren**: "Fat, Female, Forty, Fertile, Fair" — Übergewicht, weiblich, >40 Jahre, fruchtbar, hellhäutig
- **Symptome**: Kolikartiger rechtsoberbauchlicher Schmerz mit Ausstrahlung in die rechte Schulter, Übelkeit/Erbrechen
- **Diagnostik**: Sonographie (Murphy-Zeichen)
- **Therapie**: Laparoskopische Cholezystektomie (bei symptomatischer Cholelithiasis); bei akuter Cholezystitis: Antiobiotika + Cholezystektomie

## Akute Pankreatitis

- **Ätiologie**: Gallensteine (häufigste), Alkohol, Medikamente, Hypertriglyzeridämie, ERCP, Trauma, Mumps, Autoimmun
- **Symptome**: Gürtelförmiger Oberbauchschmerz, Übelkeit/Erbrechen, Fieber
- **Diagnostik**: Lipase/Amylase (≥3× oberer Normwert), Sonographie/CT
- **Schweregradeinteilung**: Ranson-Kriterien (initial 5, nach 48h 6), Glasgow-Score, CT-Schweregrad-Index (CTSI)
- **Therapie**: Volumengabe (Ringer-Laktat), Nahrungskarenz (leichte Kost peroral bei milder Pankreatitis erlaubt), Schmerztherapie, bei biliärer Genese: ERCP + Papillotomie

## Chronisch-entzündliche Darmerkrankungen (CED)

| | Morbus Crohn | Colitis ulcerosa |
|---|---|---|
| **Lokalisation** | Vom Mund bis Anus, diskontinuierlich, transmural | Kontinuierlich ab Rezialsanal → proximal, Mukosa |
| **Symptome** | Bauchschmerz, Diarrhö (nicht blutig), Fisteln, Stenosen, Abszesse | Blutig-schleimige Diarrhö, Tenesmen |
| **Rauchverhalten** | Rauchen verschlechtert | Rauchen bessert |
| **Diagnostik** | Ileokoloskopie + MRT-Enterographie | Koloskopie |
| **Therapie** | Kortikosteroide (Schub), 5-ASA (Sulfasalazin/Mesalazin), Immunsuppressiva (Azathioprin), TNF-α-Antikörper (Infliximab) | 5-ASA (Basistherapie), Kortikosteroide, Immunsuppressiva, Biologika, Kolektomie (kurativ) |
| **Extra-intestinale Manifestationen** | Gelenke (Sakroiliitis), Haut (Erythema nodosum, Pyoderma gangraenosum), Auge (Uveitis), Leber (PSC) | Ähnlich wie MC, plus PSC |
