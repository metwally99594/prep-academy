# Diagnostik

## Bildgebung

### Röntgen

| Projektion | Typische Indikationen |
|------------|----------------------|
| **Thorax p.a. + seitlich** | Pneumonie, COPD, Pneumothorax, Stauung (Herzinsuffizienz), Lungenkarzinom |
| **Abdomen (stehend + liegend)** | Ileus, Perforation (freie Luft), Steine |
| **Extremität** | Frakturnachweis, Arthrose, Osteoporose, Tumor |
| **Wirbelsäule** | Fraktur, Skoliose, Spondylarthrose |
| **Mammographie** | Mammakarzinom-Screening, klinische Abklärung |

**Röntgenzeichen**

- **Pneumothorax**: Viszerale Pleuralinie, Lungenkollaps, Mediastinalverlagerung (Spannungspneumothorax)
- **Pleuraerguss**: Verschattung des Rippen-Zwerchfell-Winkels (Menge >200ml)
- **Herzinsuffizienz-Lunge**: Vergrößerter Herz-/Thorax-Quotient (>0,5), Kerley-B-Linien, Stauungsflügel (Perihiläres Infiltrat), alveoläres Lungenödem
- **Osteoporotische Wirbelkörperfraktur**: Sinterung, Fischwirbel, Keilwirbel

### Computertomographie (CT)

- **Indikationen**: Trauma-Panorama, Tumor-Staging, Lungenembolie (CT-Angio), Schlaganfall (cCT → Blutung vs. Ischämie), Schädel-Hirn-Trauma, akutes Abdomen, Nierensteine (low-dose)
- **Kontrastmittel**: Jodhaltig → Cave: NSAR, Metformin, Niereninsuffizienz, Schilddrüsenüberfunktion, Allergie
- **Hounsfield-Einheiten**: Luft -1000, Fett -100, Wasser 0, WEICHGEWEBE +40, Knochen +400–1000

### Magnetresonanztomographie (MRT)

- **Indikationen**: Neurologie (Schlaganfall/DWI, MS, Tumor), muskuloskelettale Bildgebung (Bandscheibenvorfall, Meniskusriss, Rotatorenmanschette), Leber, Mamma, Prostata
- **Sequenzen**: T1 (anatomisch, Fett hell), T2 (Wasser hell, Pathologie), FLAIR (T2 mit unterdrücktem Liquor → MS/Ischämie), DWI (eingeschränkte Diffusion → frischer Infarkt/Abszess)
- **Kontrastmittel**: Gadolinium → Cave: nephrogene systemische Fibrose (bei Niereninsuffizienz → lineare Gd-haltige KM gemieden)
- **Kontraindikationen**: Nicht-MRT-kompatible Implantate (Herzschrittmacher, Cochlea-Implantat, ferromagnetische Clips), Klaustrophobie, Schwangerschaft kritisch

### Sonographie

- **Indikationen**: Abdomen (Leber, Gallenblase, Nieren, Pankreas, Milz, Aszites), FAST-Ultraschall (freie Flüssigkeit/Blutung nach Trauma), Echokardiographie (Pumpfunktion, Vitien, Perikarderguss), Gefäße (Duplexsonographie), Schilddrüse, Weichteile

## EKG

**Ableitungen**: 12-Kanal-EKG (Extremitäten I–III, aVR, aVL, aVF, Brustwand V1–V6)

**Systematische Auswertung**:
1. **Rhythmus**: Sinusrhythmus? Vorhofflimmern?
2. **Frequenz**: Bradykard <60, normal 60–100, Tachykard >100/min
3. **Lagetyp**: Überdrehter Linkstyp → Linksanteriore Hemiblock
4. **P-Welle**: Hypertrophie, Pulmonale → p-pulmonale (M:P pulmonal >0,12s / 2,5mm), Mitrale → p-mitrale (Notch)
5. **PQ-Zeit**: Normal <200ms, verlängert >200ms → AV-Block I°
6. **QRS**: Breite normal <0,10s (≤2,5 Kästchen), Schenkelblock (Linksschenkel >120ms)
7. **ST-Strecke**: ST-Hebung → Ischämie/Infarkt/Perikarditis; ST-Senkung → NSTEMI/Ischämie
8. **T-Welle**: T-pos. normal, T-negativ → Ischämie, Hypertrophie, LSB
9. **QT-Zeit**: Korrigiert (QTc, Bazett-Fridericia); verlängert → Torsade de pointes-Risiko (Medikamente, Hypokaliämie)

## Laborwerte

**Herzenzyme**: Troponin (I/T) → hochsensitive (hs-Tn), CK-MB, Myoglobin

**Leberwerte**: GOT/AST (~OGT ~ZYTOLYSE, mitochondriale Leber), GPT/ALT (zytosolisch→leberspezifisch), γ-GT (Cholestase/Alkohol → induzierbar), AP (Knochen-Übergang/Leber/Galle), Bilirubin (direkt / indirekt)

**Nierenwerte**: Kreatinin, eGFR (CKD-EPI), Harnstoff, Cystatin C

**Elektrolyte**: Na⁺ (Hyponatriämie → Symptom bei <125mmol/L, Krampfanfall; Hypernatriämie → Durst), K⁺ (Hyperkaliämie → EKG-Veränderungen, Hypokaliämie → Muskelschwäche, tachykarde Rhythmen), Ca²⁺ ( ↑: Steine, Knochen, Magenbeschwerden; ↓: Tetanie), Mg²⁺, Phosphat

**Blutgasanalyse**: pH, pCO₂, pO₂, HCO₃⁻, BE, Laktat → Azidose (metabolisch/respiratorisch) vs. Alkalose, Kompensation

**Infektparameter**: CRP, PCT (→ Bakterielle Infektion/Sepsis), Leukozyten, Differenzialblutbild

**Gerinnung**: Quick (PTT/INR, Vitamin-K-Faktoren), aPTT (Heparin-Kontrolle), Fibrinogen, D-Dimere, ATIII, Thrombozyten

**Schilddrüse**: TSH (Screeningparameter), fT3, fT4, TPO-AK, Tg-AK, TRAK
