# KP Vorbereitung — Amboss Zusammenfassung

**Source:** `knowledge/raw/Vorbereitung zur KP (Amboss-Zusammenfassung).pdf`

## Summary

A 588-page Amboss summary document covering the complete spectrum of medical knowledge required for the **Kenntnisprüfung (KP)** — the Austrian knowledge examination for foreign-trained physicians.

### Topics Covered

| Specialty | Key Areas |
|-----------|-----------|
| **Pneumologie** | Asthma, COPD, Pneumonie, Lungenembolie, Pleuraerguss, Lungenkarzinom, Lungenfibrose |
| **Kardiologie** | Herzinsuffizienz, KHK, Myokardinfarkt, Rhythmusstörungen, Vitien, Endokarditis, Perikarditis, Hypertonie |
| **Gastroenterologie** | GERD, Ulkuskrankheit, GI-Blutung, Reizdarm, CED (M. Crohn, Colitis ulcerosa), Hepatitis, Leberzirrhose, Pankreatitis, Cholelithiasis |
| **Innere Medizin** | Diabetes mellitus (Typ 1, Typ 2, Komplikationen), Schilddrüsenerkrankungen (Hyper-/Hypothyreose, Struma), Nebennierenrinden-Insuffizienz, Cushing, Phäochromozytom, Niereninsuffizienz, Elektrolytstörungen |
| **Neurologie** | Schlaganfall, TIA, Epilepsie, Parkinson, MS, Demenz, Meningitis, Kopfschmerz (Migräne, Spannungskopfschmerz, Cluster), Guillain-Barré, Myasthenia gravis |
| **Notfallmedizin** | ABCDE-Schema, Schock (kardiogen, hypovoläm, anaphylaktisch, septisch, neurogen), Reanimation (ALS), Atemwegsmanagement, Anaphylaxie |
| **Chirurgie** | Akutes Abdomen, Appendizitis, Cholezystitis, Ileus, Hernien, Wundheilung, Nahttechniken |
| **Orthopädie** | Frakturen (Klassifikation, Heilung), Arthrose, Osteoporose, Rückenschmerz, Bandscheibenvorfall |
| **Pharmakologie** | Vegetatives Nervensystem (Sympathikus, Parasympathikus), Kardiovaskuläre Pharmaka, Antibiotika, Analgetika (NSAR, Opioide), Lokalanästhetika |
| **Pädiatrie** | Impfungen, Kindesentwicklung, Infektionskrankheiten, Notfälle im Kindesalter, angeborene Herzfehler |
| **Gynäkologie** | Schwangerschaft, Geburtshilfe, gynäkologische Tumoren, Menstruationsstörungen, Kontrazeption |
| **Psychiatrie** | Depression, Schizophrenie, Angststörungen, Suchterkrankungen, Persönlichkeitsstörungen, Psychopharmaka |
| **Diagnostik** | Röntgen, CT, MRT, Sonographie, Kontrastmittel, EKG, Laborwerte, klinische Untersuchungstechniken |
| **Urologie** | Nierensteine, Harnwegsinfekte, Prostatakarzinom, Hodenkarzinom |
| **HNO** | Sinusitis, Tonsillitis, Hörstörungen, Schwindel, Epistaxis |
| **Dermatologie** | Ekzeme, Psoriasis, Hauttumoren (Melanom, Basaliom, Spinaliom), Infektionskrankheiten |
| **Anästhesie** | Narkoseführung, Beatmung, perioperatives Management |
| **Rechtsmedizin** | Todesfeststellung, Obduktion, Spurensicherung, toxikologische Aspekte |
| **Hygiene** | Krankenhaushygiene, Desinfektion, Sterilisation, Nosokomiale Infektionen (MRSA, VRE, C. difficile) |
| **Infektiologie** | HIV, Tuberkulose, Sepsis, Antibiotikaresistenzen, MRE |

### Additional Sections

- **Biostatistik & Evidenzbasierte Medizin**: Studiendesign, Sensitivität, Spezifität, PPV, NPV, p-Werte, Konfidenzintervalle, systematische Reviews
- **Klinische Untersuchung**: Auskultation, Perkussion, Palpation, neurologischer Status, Gefäßstatus, orientierende psychiatrische Untersuchung
- **Schmerztherapie**: Stufenschema WHO, chronischer Schmerz, Tumorschmerz
- **Ernährungsmedizin**: Mangelernährung, parenterale/enterale Ernährung, Adipositas
- **Prävention & Umweltmedizin**: Vorsorgeuntersuchungen, Impfungen, arbeitsmedizinische Aspekte
- **Sozialmedizin & Begutachtung**: Sozialrecht, Rentenantrag, Erwerbsminderung
- **Geriatrie**: Multimorbidität, Polypharmazie, Gebrechlichkeitssyndrom, Demenz,
- **Palliativmedizin**: Symptomkontrolle, Sterbebegleitung
