# Prep Academy Launch Campaign

This folder contains the local promotional campaign assets generated from real Prep Academy production screenshots.

Files:

- `02-guest-quiz.png` - live guest quiz screenshot.
- `03-login.png` - live login screenshot.
- `04-mobile-home.png` - live mobile homepage screenshot.
- `prep-academy-promo-30s.mp4` - generated 30-second promotional video.
- `prep-academy-ad-poster.png` - static campaign poster frame.
- `voiceover-de.txt` - German voiceover script.

Regenerate the video:

```powershell
.\backend\venv\Scripts\python.exe scripts\build_prep_academy_promo.py
```
